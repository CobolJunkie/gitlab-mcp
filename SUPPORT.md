# Support

Use the
[GitLab issue tracker](https://gitlab.villainmindset.org/CobolJunkie/gitlab-codex-plugin/-/issues)
for reproducible defects, compatibility problems, and feature requests. Include
the GitLab MCP distribution version, active harness (Codex, Claude Code, Cline,
Pi, or ChatGPT HTTP), Node version, GitLab version and offering, transport
(stdio or HTTP), relevant configuration names with values redacted, and the
smallest safe reproduction.

Support is community-maintained and has no guaranteed response time or service
level agreement. The latest release is the supported version.

Before opening an issue, follow the symptom-based checks in
[docs/TROUBLESHOOTING.md](docs/TROUBLESHOOTING.md).

Do not post credentials, private source code, confidential job logs, or
security vulnerabilities. Report vulnerabilities through the confidential
process in [SECURITY.md](SECURITY.md).
